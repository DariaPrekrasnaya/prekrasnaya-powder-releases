# Prekrasnaya Powder

Пудреница для рабочего стола Windows: задачи, музыка, таймер и часы.

## Скачать

**[Открыть последний выпуск и скачать установщик](https://github.com/DariaPrekrasnaya/prekrasnaya-powder-releases/releases/latest)**

В списке Assets выберите файл **Prekrasnaya-Powder-Setup-…exe**. Файлы .blockmap, latest.yml и архивы Source code скачивать для установки не нужно.

1. Скачайте установщик на компьютер с Windows x64.
2. Откройте файл и пройдите установку на русском языке.
3. Запустите пудреницу с ярлыка. Её меню находится в области значков возле часов Windows, иногда под стрелкой скрытых значков.

Музыка и сигнал таймера входят в сборку. Для iCloud Заметок используется ваш собственный вход. Сборка пока не имеет цифровой подписи издателя, поэтому Windows может показать предупреждение о неизвестном издателе.

## Обновления

Начиная с версии 0.2.0 приложение проверяет новые выпуски при запуске и каждые 6 часов. Проверить вручную можно через меню «Проверить обновления» возле часов Windows. Вы сами выбираете, когда скачать обновление и перезапустить приложение. Задачи и настройки хранятся отдельно от программы.

Если у вас версия 0.1.0, один раз установите свежую версию вручную.
