## Установка

**Windows:** откройте EXE и пройдите установку на русском языке. Меню пудреницы находится возле часов, иногда под стрелкой скрытых значков. Windows может показать предупреждение о неизвестном издателе: платной подписи у приложения нет.

**Mac:** откройте DMG, перетащите Prekrasnaya Powder в Applications («Программы»), затем запустите из «Программ». Меню пудреницы находится в верхней строке меню.

Mac-версия без платного сертификата и проверки Apple. После первой попытки запуска macOS может потребовать «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть». Разрешайте только приложение, которое вы сами скачали отсюда и которому доверяете. На управляемом рабочем Mac запуск может быть ограничен администратором. Отключать защиту системы целиком не нужно. [Объяснение Apple](https://support.apple.com/102445).

Музыка и сигнал таймера уже внутри. GitHub-аккаунт не нужен. Для iCloud нужен собственный вход; чужие заметки, задачи и пароли не входят в сборку.

## Обновления

Обе платформы получают уведомления о новых версиях. Проверка происходит после запуска и каждые 6 часов; в меню есть «Проверить обновления».

- **Windows:** «Скачать обновление», затем «Перезапустить и установить». Можно отложить оба шага.
- **Mac:** «Скачать для Mac» откроет подходящий DMG. Выйдите из старой пудреницы через её меню и замените приложение в «Программах». При следующем запуске macOS может снова запросить разрешение. Автоматической замены приложения без участия пользователя в Mac-версии нет.

Миссии, настройки и вход в iCloud хранятся отдельно от программы. Не удаляйте папку данных при обновлении.
